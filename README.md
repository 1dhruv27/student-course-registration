# Student Course Registration System

A full-stack web application that allows students to securely register, log in, view available courses, and enroll in classes online. 

## 🚀 Features

* **User Authentication:** Secure student registration and login functionality.
* **Interactive Dashboard:** Students can view a dynamic list of available courses.
* **Enrollment System:** Real-time course enrollment that tracks course capacity and prevents double-enrollment.
* **Responsive UI:** A clean, user-friendly frontend built with HTML5, CSS3, and Vanilla JavaScript.
* **RESTful API:** A robust Node.js/Express backend handling data routing and processing.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (DOM API, Fetch API)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Tools:** VS Code, Git, Browser DevTools

## 📋 Prerequisites

Before running this project, ensure you have the following installed on your local machine:
* [Node.js](https://nodejs.org/)
* [MongoDB](https://www.mongodb.com/try/download/community) (Running locally via MongoDB Compass or a MongoDB Atlas URI)
